# Software Requirements Specification (SRS)

## 1. Introduction

This document describes the requirements for the Digital Incident & Near-Miss Reporting System.

## 2. Purpose

The purpose of this system is to digitally record, track, and manage incidents and near-miss events.

## 3. Scope

The system supports reporting, monitoring, and analysis of incidents for improved security and risk prevention.

## 4. Users

- Administrator
- Registered User
- Security Officer

## 5. Functional Requirements

- User registration and login
- Incident and near-miss reporting
- Incident status tracking
- Role-based access control
- Report viewing and management

## 6. Non-Functional Requirements

- Security
- Reliability
- Scalability
- Performance

## 7. Future Enhancements

- Analytics dashboard
- Email notifications
- Mobile application support
