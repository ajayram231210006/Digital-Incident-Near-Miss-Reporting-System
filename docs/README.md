# Documentation Layout

This folder keeps project documentation grouped by purpose so the repository root stays focused on application code and core config.

- `guides/`: implementation notes, system guides, quick references, and flow docs
- `testing/`: QA checklists and testing walkthroughs
- `security/`: security-related notes and rule references
- `presentations/`: project presentation assets
- `notes/`: temporary working notes and continuation docs
- `archive/`: older backups kept for reference
